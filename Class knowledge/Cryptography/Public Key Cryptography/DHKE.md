# Diffie–Hellman 密钥交换


目标：在一个**不安全的公开信道**上（窃听者 Eve 在场），让 Alice 与 Bob 安全协商出一个**共享秘密** (K)，供后续对称加密使用——而无需事先共享密钥。

Diffie–Hellman（DH）利用模指数运算的单向性来实现这一点：前向计算容易，逆向（求离散对数）困难。

双方事先同意并公开两个参数（Eve 也知道）：

* 一个大素数 (p)（模数）
* 基数（生成元） (g)（通常是模 (p) 的原根或合适的基）

（注：实际中 (p) 要很大，例如 2048 位或更大，且 (g) 的选取需按规范；下面示例用小数便于演示。）

示例（演示用）：
[
p = 23,\quad g = 5
]

---

## 1、协议步骤

### 1.1. 私钥选择（各自保密）

* Alice 随机选择私钥 (a = 6)（保密）
* Bob 随机选择私钥 (b = 15)（保密）

### 1.2. 生成并公开公钥

各自计算公钥并通过公开信道发送：

* Alice 计算： (A = g^a \bmod p = 5^6 \bmod 23)
  逐步计算：

  * (5^2 = 25 \equiv 2 \pmod{23})
  * (5^4 = (5^2)^2 \equiv 2^2 = 4 \pmod{23})
  * (5^6 = 5^4 \cdot 5^2 \equiv 4 \cdot 2 = 8 \pmod{23})
    → 所以 (A = 8)。Alice 把 (A=8) 公开给 Bob。

* Bob 计算： (B = g^b \bmod p = 5^{15} \bmod 23)
  逐步（按二进制分解指数）：

  * 我们已知： (5^1=5,;5^2\equiv2,;5^4\equiv4,;5^8\equiv (5^4)^2\equiv4^2=16\pmod{23})
  * 将 15 分解为 (8+4+2+1)，则
    [
    5^{15}=5^8\cdot5^4\cdot5^2\cdot5^1 \equiv 16\cdot4\cdot2\cdot5
    ]
    依次计算：

    * (16\cdot4 = 64 \equiv 64-2\cdot23 = 64-46 = 18)
    * (18\cdot2 = 36 \equiv 36-1\cdot23 = 13)
    * (13\cdot5 = 65 \equiv 65-2\cdot23 = 65-46 = 19)
      → 所以 (B = 19)。Bob 把 (B=19) 公开给 Alice。

Eve 能看到：公有参数 (p=23,g=5) 以及公钥 (A=8, B=19)。

### 1.3 计算共享秘密（各自用对方公钥 + 自己私钥）

* Alice 用 Bob 的公钥 (B) 与自己的私钥 (a)：
  [
  K = B^a \bmod p = 19^6 \bmod 23
  ]
  逐步：

  * (19^2 = 361 \equiv 361 - 15\cdot23 = 361-345 = 16)
  * (19^4 = (19^2)^2 \equiv 16^2 = 256 \equiv 256 - 11\cdot23 = 256-253 = 3)
  * (19^6 = 19^4\cdot19^2 \equiv 3\cdot16 = 48 \equiv 48 - 2\cdot23 = 48-46 = 2)
    → Alice 得到 (K=2)。

* Bob 用 Alice 的公钥 (A) 与自己的私钥 (b)：
  [
  K' = A^b \bmod p = 8^{15} \bmod 23
  ]
  逐步（利用指数分解 15 = 8+4+2+1）：

  * (8^1 = 8)
  * (8^2 = 64 \equiv 64-2\cdot23 = 18)
  * (8^4 = (8^2)^2 \equiv 18^2 = 324 \equiv 324-14\cdot23 = 324-322 = 2)
  * (8^8 = (8^4)^2 \equiv 2^2 = 4)
  * (8^{15} = 8^8\cdot8^4\cdot8^2\cdot8^1 \equiv 4\cdot2\cdot18\cdot8)
    依次：

    * (4\cdot2=8)
    * (8\cdot18=144 \equiv 144 -6\cdot23 = 144-138 = 6)
    * (6\cdot8 = 48 \equiv 48-2\cdot23 = 2)
      → Bob 也得到 (K'=2)。

因此 Alice 与 Bob 最终共享同一个秘密：(K = 2)。


### 1.4、数学原理

因为
[
B^a \bmod p = (g^b)^a \bmod p = g^{ba} \bmod p
]
而
[
A^b \bmod p = (g^a)^b \bmod p = g^{ab} \bmod p
]
由于乘法在指数上可交换，(g^{ab}=g^{ba})，所以两边得到相同值 (g^{ab}\bmod p)。
