# 椭圆曲线密码学（ECC）

## 1. 椭圆曲线是什么（直观与代数形式）

* 在代数上，一条（非奇异）椭圆曲线 (E) 在实数域常用的简化方程是
  (y^2 = x^3 + a x + b)，并要求判别式 (4a^3 + 27b^2 \ne 0)（保证没有尖点或自交点）。
  注：尽管名字里有“椭圆”，曲线形状通常并非椭圆形。

* **密码学里不使用实数域**，而是把曲线定义在**有限域**上（例如模素数 (p) 的域 GF(p)）。
  在有限域上，点 ((x,y)) 满足
  [
  y^2 \equiv x^3 + a x + b \pmod p.
  ]
  在 GF(p) 中，曲线上的点是散落在 (p\times p) 网格上的有限集合，还包括一个特殊的“无穷远点” (O)，作为群的单位元。

---

## 2. 点加法（群运算）：几何直观与代数公式

椭圆曲线上所有点（含 (O)）构成一个 **阿贝尔群**（满足交换律与结合律），群运算是“点加法”。

### 2.1 几何直观

* 若 (P) 与 (Q) 是曲线上两点：

  1. 作穿过 (P) 与 (Q) 的直线（若 (P=Q) 则取切线）。
  2. 直线一般与曲线再交第三点 (R')。
  3. 将 (R') 关于 (x)-轴反射（取相反的 (y)），得到点 (R)。定义 (P+Q=R)。

* 负点（逆元）：若 (P=(x,y))，则 (-P=(x, -y \bmod p))，满足 (P+(-P)=O)。

### 2.2 代数公式（在有限域 GF(p) 上）

设 (P=(x_1,y_1)) 和 (Q=(x_2,y_2))，计算 (R=(x_3,y_3)=P+Q)。

* 若 (P\ne Q) 且 (x_1\ne x_2)：

  * 斜率 (\lambda = (y_2 - y_1)\cdot (x_2 - x_1)^{-1} \pmod p)。
    这里的 “((x_2-x_1)^{-1})” 表示在模 (p) 下的逆元（用扩展欧几里得算法求得）。
  * (x_3 = \lambda^2 - x_1 - x_2 \pmod p).
  * (y_3 = \lambda (x_1 - x_3) - y_1 \pmod p).

* 若 (P = Q)（点倍，求 (2P)），且 (y_1 \not\equiv 0 \pmod p)：

  * 切线斜率 (\lambda = (3x_1^2 + a)\cdot (2y_1)^{-1} \pmod p).
  * 同样用 (x_3 = \lambda^2 - 2x_1 \pmod p)，(y_3 = \lambda(x_1 - x_3) - y_1 \pmod p).

* 若 (x_1 \equiv x_2) 且 (y_1 \equiv -y_2)（即 (Q=-P)），则 (P+Q=O)。

> 重要实现点：公式中出现的“除法”在有限域中通过求模逆（扩展欧几里得）来实现；如果分母没有逆（即与 (p) 不互素），需要按特殊情况处理（通常那时结果是无穷远点或无效）。

---

## 3. 标量乘法（Scalar multiplication）与计算方法

* **定义**：给定基点 (G)（公开参数）和整数私钥 (k)，标量乘法是 (P = k\cdot G)，即把 (G) 与自身相加 (k) 次。
* **高效算法**：使用“倍加法（double-and-add）”或其各种优化（窗口法、GLV、Montgomery ladder 等）以二进制方式递归计算，时间复杂度与 (k) 的位数成比例。
* **用途**：私钥是整数 (k)，公钥是点 (P=kG)。

---

## 4. 具体实例

我们用一个简单的示例曲线，便于手算：

* 域：( \mathbb{F}_p )（模 (p) ），取 (p=17)。
* 椭圆曲线：( E: y^2 \equiv x^3 + 2x + 2 \pmod{17} ).
  （判别式 (4a^3+27b^2 = 140 \equiv 4 \not\equiv 0\pmod{17})，曲线合法）
* 选一个基点（公开）： (G = (5,1))。
  （在这个域上，(G) 的确是曲线上的点；下面我们也会看到 (2G=(6,3))、(3G=(10,6)) 等点）

> 说明：在真实世界中 (p) 和点都非常大，这里用小数只是为了演示算术。

---

### 4.1 先回顾：为何需要模逆（来自之前的数论知识）

点加/倍的代数公式需要“除法”——例如斜率公式中会出现除以 (x_2-x_1) 或 (2y_1)。在模运算中，这个“除法”是用**模逆元**来实现的：若我们要算 (a/b \pmod p)，等价于 (a \cdot b^{-1} \pmod p)，其中 (b^{-1}) 满足 (b\cdot b^{-1}\equiv1\pmod p)。模逆用**扩展欧几里得算法（EEA）**求出。

举两个小例（方便后面看斜率计算）：

1. (2^{-1}\bmod17)。

   * 因为 (17 = 8\cdot2 + 1) → (1 = 17 - 8\cdot2)。
   * 故 ( -8\cdot2 \equiv 1 \pmod{17})，于是 (2^{-1}\equiv -8 \equiv 9 \pmod{17})。
   * 验证： (2\cdot9=18\equiv1\pmod{17})。

2. (16^{-1}\bmod17)。

   * (17 = 1\cdot16 + 1) → (1 = 17 - 1\cdot16)，所以 (16^{-1}\equiv -1 \equiv 16).
   * 验证： (16\cdot16 =256\equiv1\pmod{17})。

3. (12^{-1}\bmod17)（在后面会用到）——用 EEA 回代可以得到 (12^{-1}\equiv 10\pmod{17})。（检验：(12\cdot10=120\equiv1\pmod{17})）

---

### 4.1：点倍（Doubling） — 计算 (2G)

我们要计算 (2G)（即 (G+G)），公式如下（在有限域 (\bmod p)）：

若 (P=(x_1,y_1))，
[
\lambda = \frac{3x_1^2 + a}{2y_1}\pmod p,\quad
x_3 = \lambda^2 - 2x_1\pmod p,\quad
y_3 = \lambda(x_1 - x_3) - y_1\pmod p.
]

带入 (G=(5,1))、曲线系数 (a=2)、模 (p=17)：

1. 计算分子： (3x_1^2 + a = 3\cdot5^2 + 2 = 3\cdot25 +2 = 75+2=77).
   (77 \bmod 17 = 77 - 4\cdot17 = 77-68 = 9).

2. 计算分母： (2y_1 = 2\cdot1 = 2). 我们已知 (2^{-1} \equiv 9)（上面 EEA），所以分母的逆是 9。

3. 斜率： (\lambda \equiv 9 \cdot 9 \bmod 17 = 81 \bmod 17 = 13).

4. (x_3 = \lambda^2 - 2x_1 \equiv 13^2 - 10 = 169 - 10 =159 \bmod 17).
   (159 - 9\cdot17 = 159-153 = 6). 所以 (x_3=6).

5. (y_3 = \lambda(x_1 - x_3) - y_1 = 13(5-6)-1 = 13(-1)-1 = -13 -1 = -14 \bmod 17).
   (-14 \bmod 17 = 3). 所以 (y_3 = 3).

结果： (2G = (6,3)).（并且你可以在之前我列出的点集里看到 ((6,3)) 确实在曲线上）

---

### 4.2：点加（Addition） — 计算 (P+Q)（示例： (2G + G = 3G)）

用 (P=(6,3))（即 (2G)）和 (Q=G=(5,1))。公式（当 (P\ne Q)）：

[
\lambda = \frac{y_2 - y_1}{x_2 - x_1} \pmod p,\quad
x_3 = \lambda^2 - x_1 - x_2,\quad
y_3 = \lambda(x_1 - x_3) - y_1.
]

带入 (P=(6,3),\ Q=(5,1))：

1. 分子 (y_2-y_1 = 1-3 = -2 \equiv 15 \pmod{17}).
2. 分母 (x_2-x_1 = 5-6 = -1 \equiv 16 \pmod{17}). 我们知道 (16^{-1}\equiv16)（见上文）。
3. (\lambda \equiv 15\cdot 16 \bmod17 = 240\bmod17 = 2).
4. (x_3 = 2^2 - 6 - 5 = 4 -11 = -7 \equiv 10).
5. (y_3 = 2(6-10) - 3 = 2(-4)-3 = -8 -3 = -11 \equiv 6).

结果： (3G = (10,6)).（验证：确实在我们的点集中）

---

### 4.3：标量乘法（Double-and-Add）示范：计算 (3G) 用二进制分解

标量乘法用于计算 (kG)（把 (G) 加自己 (k) 次）。常用算法是 **double-and-add**（类似快速幂）：

* 把 (k) 写成二进制。从最高位向低位遍历：

  * 维护累加器 (R)（初始为 (O)），当前点 (N)（初始为 (G)）。
  * 每位：若位为1，则 (R \leftarrow R + N)。然后 (N \leftarrow 2N)。继续下一位。

示例： (k=3)（二进制 `11`）：

* 初始 (R=O,\ N=G).
* 低位或高位方式任一（常见实现会自右向左或左向右），用我们前面的计算：先算 (2G=(6,3))，再 (3G=(6,3)+G=(10,6))。与上面手算结果一致。

---

### 4.4：把 ECC 与 DH 的标量/指数对应起来（ECDH 演示）

现在把上面操作放到 **密钥交换（ECDH）** 的语境下，直接类比模 DH：

* Alice 私钥 (a=2)。她的公钥 (A=aG = 2G = (6,3)).
* Bob 私钥 (b=3)。他的公钥 (B=bG = 3G = (10,6)).

双方互换 (A, B)。共享密钥计算（Alice 计算 (aB)，Bob 计算 (bA)）：

* Alice 计算 (S = aB = 2\cdot(10,6))。我们用点倍公式算 (2\cdot(10,6)=(16,13))。
* Bob 计算 (S' = bA = 3\cdot(6,3))。通过 double-and-add（或先算 (2(6,3)) 再加一次 (6,3)）也得到 ((16,13))。

所以两边共享相同点 (S=(16,13))。这就是 ECDH：共享秘密是曲线上一个点（或该点的 (x) 坐标），类似于经典 DH 中的 (g^{ab})。
