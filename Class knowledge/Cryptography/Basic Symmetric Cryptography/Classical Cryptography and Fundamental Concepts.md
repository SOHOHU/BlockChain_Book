# 古典密码与密码学核心原则
---

## 1) 什么是密码学？——最基础的词汇与意图

* **明文（Plaintext）**：你想保护的原始信息（例如：`HELLO`）。
* **密文（Ciphertext）**：经过加密后得到的“乱码”（例如：`KHOOR`）。
* **密钥（Key）**：控制加密/解密的秘密参数（例如：移位 3）。
* **加密（Encrypt）**：把明文 + 密钥 → 密文的过程。
* **解密（Decrypt）**：把密文 + 密钥 → 明文的过程。

**密码学的核心目标（常见三项）**：

* **机密性（Confidentiality）**：只有授权方可以读懂消息。
* **完整性（Integrity）**：消息在传输中未被篡改。
* **不可否认性（Non-repudiation）**：发送者不能否认自己发送过消息（通常靠签名实现）。

> 注：这里我们关注的是对称密码学（symmetric cryptography），即加密与解密使用**同一个密钥**。

## 2) 古典密码：替换与换位（手工时代的做法）

古典密码通常用很直观的方式改变文字：把字母替换成别的字母（替换密码），或把字母位置重新排列（换位密码）。

### 2.1 凯撒密码（Caesar Cipher）——最容易理解的例子

**做法**：把字母表中的每个字母“移位”固定数字。
例：密钥 = `3`（向右移 3）

* `A → D, B → E, C → F, ... , X → A, Y → B, Z → C`

示例：

* 明文：`HELLO`
* 加密（移位 3）：`KHOOR`
* 解密（移位 -3）：`HELLO`

**为什么不安全？**

* 英文字母只有 26 个，移位可能只有 25 种（移位 26 相当于原文）。攻击者可以尝试 25 次就能穷举出真实明文——对计算机来说瞬间完成（暴力破解）。
* 频率分析：某些字母在英文中更常见（如 E），替换不会改变字母出现频率，因此可统计攻击。

### 2.2 密钥空间（Key Space）—直观理解

* **密钥空间**：所有可能密钥的数量。安全性的一部分就是密钥空间够大，暴力破解不可行。
* 例：凯撒密钥空间大小 = 25（几乎可忽略）。
* 现代推荐：密钥长度至少达到能覆盖 `2^128` 个可能（对称密钥），这使穷举变得不现实。

## 3) 进阶古典例子：恩尼格玛（ENIGMA）机器——机械化的多表替换

Enigma 是二战时期德国用于加密的机电设备，看起来复杂，但思想可分解成：多个逐步变化的替换表（rotors）+ 接线板（plugboard）。

**主要特点（直观）**：

* 每按一次键，内部转子转动，替换规则随之改变 → 属于 **多字母替换（polyalphabetic）**。
* 因为替换随时间变化，同一个明文字母在不同位置可能被映射为不同密文字母，从而破坏简单频率分析。

**为什么仍被破解？**

* 虽然按理密钥空间巨大，破解者（波兰/英国团队）利用了：

  * 操作失误（如重复的密钥设置、常见短语、发送习惯）。
  * 已知明文或猜测明文（“cribs”）。
  * 数学上的巧妙分析与机械化试验（如图灵的 Bombe）。
* 教训：**实现和操作上的失误**会使系统不安全；安全不能靠“算法保密”而应靠密钥保密（柯克霍夫原则）。

## 4) 理想情况：一次性密码本（One-Time Pad, OTP）——数学上“完美”的方案

**工作方式（非常直观）**：

* 准备一段与明文等长的完全随机比特串（密钥流）。
* 将明文和随机比特串逐位做 XOR（异或）。结果是密文。
* 接收方使用同样的随机比特串做 XOR，即可恢复明文。

**为什么称为“完美机密性”？**

* 如果密钥是**真正随机**、**和明文等长**、并且**只使用一次**，则密文对攻击者不泄露任何关于明文的信息——数学上可证明（信息论意义上的完美安全）。攻击者看到密文，任意可能的明文都能与某个密钥匹配。

**现实问题（为何很难实际使用）**：

1. **密钥生成要真正随机** —— 伪随机不够（攻击者可能推断出模式）。
2. **密钥长度必须与明文同长** —— 要传输和储存大量随机密钥。
3. **密钥绝对不能重复使用** —— 一旦重复（如 VENONA 案例），攻击者可以联立两个密文消除密钥，从而恢复信息。

**小示例（位操作）**：

* 明文（位）： 1 0 1 1
* 密钥（随机）： 0 1 0 0
* 密文 = 明文 XOR 密钥 = 1⊕0 0⊕1 1⊕0 1⊕0 = 1 1 1 1
* 解密：密文 XOR 密钥 = (1 1 1 1) XOR (0 1 0 0) = 1 0 1 1（回到明文）

## 5) 现代密码的设计原则（Claude Shannon）：混淆（Confusion）与扩散（Diffusion）

Shannon 在信息论和密码学奠基中提出：为了让密码安全，必须同时实现**混淆**与**扩散**。

### 5.1 混淆（Confusion）

**目标**：让密文与密钥之间的直接关系变得非常复杂、难以推断。
**直观手段**：使用 **非线性替换**（例如 S-盒子 —— substitution box），使得密文位与密钥位之间的映射不再是简单线性关系（不可通过简单方程推导）。

示例直观理解：

* 如果密钥的某一位改变，期望密文中的许多位发生复杂且不可预测的改变（不能简单地追踪回哪一位是如何影响的）。

### 5.2 扩散（Diffusion）

**目标**：把明文中单个比特/字母的统计特征扩散到密文的多个位置，使得攻击者无法通过频率或统计分析找出原文信息。
**直观手段**：大量置换与线性混合（例如置换层、混合层），使得输入的每个位影响输出的很多位。

合在一起：

* **混淆**负责将密钥与密文关系复杂化（增加攻击难度）。
* **扩散**负责把明文的局部统计特征打散到全局，破坏频率等泄露信息。

### 5.3 在现代分组密码中的体现（以 AES 为例的高层直觉，后续我们会介绍到）

AES（高级加密标准）的大致架构包含：

* 多轮（rounds）的替换（S-box，提供混淆）和置换/混合（ShiftRows / MixColumns，提供扩散）。
* 每轮也会与轮密钥（由主密钥扩展得来）进行异或操作，保证密钥在各轮中持续影响结果。

> 直观比喻：把明文当作一张纸，上面写着信息。混淆像在纸上多次把字母替换成复杂的符号；扩散像把纸揉碎、撕成很多小片再重新拼 — 这样单个字母的信息被散到每一片上。
