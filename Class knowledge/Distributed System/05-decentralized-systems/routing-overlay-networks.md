# 路由覆盖网络

## 📌 覆盖网络

**覆盖网络（Overlay Network）**：构建在物理网络之上的虚拟网络

### 关键问题

如何高效地路由查询？

### 路由方案对比

| 方案 | 路由信息 | 查询复杂度 |
|------|---------|-----------|
| 仅后继节点 | O(1) | O(N) |
| 所有节点 | O(N) | O(1) |
| Chord | O(log N) | O(log N) |

## 🎯 设计目标

1. **去中心化**：无中心节点
2. **可扩展**：支持大量节点
3. **高效查询**：O(log N)
4. **容错**：节点动态加入/离开
