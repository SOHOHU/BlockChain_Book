# 全局状态

## 📌 问题

**全局状态**：所有进程状态+所有通道状态的集合

**挑战**：
- 没有全局时钟
- 无法同时观察所有进程
- 消息在传输中

## 🎯 一致性全局状态

### 一致性切割（Consistent Cut）

**定义**：如果e → f且f在切割中，则e也必须在切割中

```
P1: e1 → e2 → e3
        ↓ m
P2: f1 → f2 → f3

一致切割：{e2, f1} ✓
不一致切割：{e1, f2} ✗（f2收到e2的消息，但e2不在切割中）
```
