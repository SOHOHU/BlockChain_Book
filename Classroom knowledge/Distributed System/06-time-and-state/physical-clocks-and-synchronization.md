# 物理时钟与同步

## 📌 时钟问题

**问题**：分布式系统没有全局时钟

### 时钟漂移

```
理想时钟：每秒恰好走1秒
实际时钟：存在漂移率

漂移率：10^-6 到 10^-7
即每秒差1微秒
```

## ⏰ 时钟同步算法

### 1. Cristian算法

**流程**：
```
客户端A请求服务器B的时间
记录往返时间T_round
设置时钟为：t + T_round/2
```

**精度**：± T_round/2

### 2. Berkeley算法

**流程**：
```
1. 主节点轮询所有从节点时间
2. 计算平均时间
3. 发送调整量给各节点
```

### 3. NTP（Network Time Protocol）

**特点**：
- 互联网标准
- 层次化结构
- 毫秒级精度

## 🔑 关键要点

1. **时钟漂移**：物理时钟不完美
2. **同步算法**：Cristian、Berkeley、NTP
3. **精度**：取决于网络延迟
