# 被动复制与主动复制

## 📌 被动复制（Passive Replication）

**也称**：主从复制（Primary-Backup）

### 架构

```
客户端 ─────> 主副本 ────同步───> 备份副本
        请求     │                    │
        响应 <───┘                    │
                                      │
              主副本失效时切换 <──────┘
```

### 流程

```
1. 客户端请求发送给主副本
2. 主副本处理请求
3. 主副本同步状态到备份副本
4. 主副本响应客户端
5. 主副本失效时，备份升级为主副本
```

### 优缺点

**优点**：
- ✅ 简单
- ✅ 强一致性

**缺点**：
- ❌ 主副本是瓶颈
- ❌ 故障切换有延迟

## 📌 主动复制（Active Replication）

**也称**：状态机复制

### 架构

```
客户端 ──┬──> 副本1
         ├──> 副本2
         └──> 副本3
           所有副本并行处理
```

### 流程

```
1. 客户端请求广播给所有副本
2. 所有副本以相同顺序执行请求
3. 任一副本响应客户端
4. 副本失效不影响服务
```

### 要求

**确定性**：
- 相同输入→相同输出
- 相同顺序执行

**原子广播**：
- 所有副本收到相同消息
- 相同顺序

### 优缺点

**优点**：
- ✅ 高可用性
- ✅ 无单点故障
- ✅ 快速故障恢复

**缺点**：
- ❌ 复杂
- ❌ 消息开销大
- ❌ 需要确定性操作

## 🔑 关键要点

1. **被动复制**：主备模式，简单但主副本是瓶颈
2. **主动复制**：所有副本并行，高可用但复杂
3. **选择**：根据应用需求权衡
