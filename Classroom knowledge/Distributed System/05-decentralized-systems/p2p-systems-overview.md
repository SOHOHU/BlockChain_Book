# P2P系统概述

## 📌 什么是P2P？

**P2P（Peer-to-Peer）**：对等网络，所有节点地位平等，既是客户端也是服务器。

### Client-Server vs P2P

```
Client-Server:
┌────┐  ┌────┐
│C1  │  │C2  │
└─┬──┘  └─┬──┘
  └───┬───┘
      ▼
  ┌───────┐
  │Server │ ← 单点故障，性能瓶颈
  └───────┘

P2P:
  ┌────┐
  │ P1 │
  ↙  ↓  ↘
┌─┐ ┌─┐ ┌─┐
│P2│ │P3│ │P4│ ← 去中心化，可扩展
└─┘ └─┘ └─┘
```

## 🎯 P2P优势

1. **可扩展性**：节点越多，资源越多
2. **容错性**：无单点故障
3. **成本低**：利用边缘节点资源
4. **自组织**：动态加入/离开

## 📊 P2P类型

### 1. 非结构化P2P

**特点**：节点随机连接

**示例**：Gnutella
- 泛洪查询
- 简单但效率低

### 2. 结构化P2P

**特点**：节点按特定拓扑组织

**示例**：Chord, Pastry, Kademlia
- 高效查询（O(log N)）
- 复杂但可扩展

### 3. 混合P2P

**特点**：结合中心化和P2P

**示例**：Napster
- 中心服务器索引
- P2P数据传输

## 🔑 关键要点

1. **P2P**：去中心化，节点平等
2. **优势**：可扩展、容错、低成本
3. **类型**：非结构化、结构化、混合
