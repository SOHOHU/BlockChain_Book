# Napster与混合架构

## 📌 Napster架构

### 混合P2P模型

```
1. 中心服务器：维护文件索引
2. P2P传输：直接传输文件

流程:
Peer A ──查询"song.mp3"──> 中心服务器
Peer A <──"在Peer B"────── 中心服务器  
Peer A ──下载文件────────> Peer B
```

## 🔧 工作流程

```
1. 连接：Peer连接到中心服务器
2. 发布：告知服务器自己有哪些文件
3. 搜索：查询服务器找到文件位置
4. 下载：直接从其他Peer下载
```

## ⚖️ 优缺点

**优点**：
- ✅ 快速查找
- ✅ 简单实现

**缺点**：
- ❌ 中心服务器是单点故障
- ❌ 可扩展性受限
- ❌ 法律问题（版权）
