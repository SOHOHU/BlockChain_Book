
## 后量子密码学 (Post-Quantum Cryptography, PQC)

### 1. 量子威胁：为什么我们需要 PQC？


目前全球数字安全赖以生存的基石——**公钥密码系统（如 RSA、ECC）**，建立在一些数学上的“高墙”之上，这些墙被认为在现有（经典）计算机上是无法逾越的。然而，量子计算机的发明者彼得·秀尔（Peter Shor）和洛夫·格罗弗（Lov Grover）提出的算法，理论上将直接推倒这些墙。

| 密码系统 | 安全性基础（经典计算机难题） |
| :--- | :--- |
| **RSA** | **大整数分解问题 (Factoring)**：给定一个极大整数 $N$，找出构成它的两个大素数 $p$ 和 $q$。 |
| **DHKE / ECC** | **离散对数问题 (Discrete Logarithm)**：给定 $g^a$ 和 $g$，求出指数 $a$。 |

这些问题在经典计算机上解决需要**指数级**的时间（比如几万年），因此被认为是安全的。

#### 1.1 Shor 算法：公钥密码的“死刑判决”

**Shor 算法**是量子计算领域最具颠覆性的发现，它直接针对上述两种数学难题：

* **目标：** Shor 算法能在量子计算机上高效解决大整数分解和离散对数问题。
* **颠覆性结果：**
    * **时间复杂度降级：** 它将解决这些难题所需的时间复杂度从“指数级”（即极长）降到了**“多项式时间”（即非常快，在可接受的计算时间内）**。
    * **瞬间失效：** 这意味着一旦一台足够强大的量子计算机问世， **RSA、DHKE 和 ECC** 等主流公钥加密和数字签名算法将**瞬间失去安全保障**。

#### 1.2 Grover 算法：加速对称密码的破解

**Grover 算法**是量子计算的另一个重要算法，但它带来的威胁相对较小。

* **目标：** Grover 算法主要用于对**无结构数据**进行搜索，这在密码学中体现为**暴力破解（Brute-Force Attack）**。
* **应对措施：** 密码学家无需更换算法，只需**将密钥长度加倍**。例如，将常用的 **AES-128 升级到 AES-256**。这样，破解所需的计算量又回到了 $2^{128}$，使其在可预见的未来保持安全。因此，对称加密体制受到的影响相对较小。

#### 1.3. “先收割，后解密”攻击 (Harvest Now, Decrypt Later, HNDL)

HNDL 攻击是当前最具紧迫性的量子威胁，因为它**现在就可以开始实施**，而不需要等待量子计算机真正建成。

* **威胁紧迫性：** 虽然大规模、通用型的量子计算机可能还需要 10-20 年才能出现，但攻击者知道历史数据（如商业秘密、医疗记录、国家机密）的价值往往很高，需要**长期保密**。
* **攻击模式（今天的行动）：**
    1.  恶意行为者（攻击者）**在今天**通过窃听网络流量、入侵数据库等方式，大规模地**截获并存储**所有使用现有 RSA 或 ECC 加密保护的敏感数据。
    2.  由于他们没有私钥，今天无法解密这些密文。
* **攻击后果（未来的兑现）：**
    1.  当**未来**足够强大的量子计算机出现后，攻击者将利用 **Shor 算法**快速破解这些密钥。
    2.  他们用破解的密钥解密**今天**截获并存储的密文，从而窃取所有敏感信息。

### 2. 后量子密码学 (PQC) 的定义与目标

1.  **在今天的经典计算机上高效运行：** PQC 算法必须是可实现、可部署的。它们不依赖于量子硬件，而是像我们现在使用的 RSA 或 ECC 一样，在传统的 CPU 和内存上运行。
2.  **能够抵御未来的量子计算机攻击：** PQC 算法必须基于量子计算机理论上无法高效解决的新数学难题。

简而言之，PQC 不是**量子密码学**（例如量子密钥分发 QKD，它依赖量子物理特性和特殊的量子硬件），而是**经典算法**，旨在应对量子计算带来的威胁。它是为**后量子时代**准备的“经典工具”。

### 3. PQC 的数学基础与算法家族

后量子密码学（PQC）的核心思想是“换掉数学难题”。它不再使用 Shor 算法可以高效解决的**大整数分解**或**离散对数**，而是转向一些全新的、被认为在量子计算机上也难以攻克的数学结构。

以下是目前主流的三个 PQC 算法家族，以及它们各自的安全基础和代表算法：

#### 3.1. 基于格的密码学 (Lattice-based Cryptography)

这是目前 PQC 领域最被看好，也是标准化进程最快的家族。NIST（美国国家标准与技术研究院）选择的两个核心算法都属于这一类。

* **安全基础：**
    “格”在数学上可以理解为多维空间中点的规则排列。基于格的密码学依赖于格上的某些困难问题，例如：
    * **最短向量问题 (Shortest Vector Problem, SVP)：** 在一个高维格中找到一个长度最短的非零向量。
    * **最近向量问题 (Closest Vector Problem, CVP)：** 在一个高维格中找到距离给定目标点最近的格点。
    * **困难性：** 即使是量子计算机，也被认为无法在多项式时间内高效解决这些格问题。

* **优点：**
    * **效率高：** 加密和解密操作通常涉及简单的多项式运算，非常适合在经典计算机上快速运行。
    * **结构简洁：** 理论研究成熟，且具有**平均情况安全性**（即如果最坏情况的实例很难解决，那么大多数随机实例也很难解决），这在密码学中是非常理想的特性。

* **代表算法：**
    * **CRYSTALS-Kyber (密钥封装机制/加密)：** 被 NIST 选为通用加密和密钥交换的标准。它的优势在于**密钥体积小**且**运算速度快**。
    * **CRYSTALS-Dilithium (数字签名)：** 被 NIST 选为主要的数字签名标准。

#### 3.2. 基于哈希的密码学 (Hash-based Cryptography)

这是 PQC 中安全性**理论上最可靠**的家族，因为它的安全性只依赖于**哈希函数的抗碰撞性**，而哈希函数（如 SHA-256）受量子计算的影响相对较小（Grover 算法只会将破解速度提升一倍，可以通过增加输出长度来抵消）。

* **安全基础：**
    * **抗碰撞性：** 找到两个不同的输入，使它们产生相同的哈希输出，在计算上是不可行的。
    * **构造：** 该家族主要用于**数字签名**，通过将多次哈希操作组合起来，创建一个基于哈希链或哈希树的签名方案。

* **优点：**
    * **量子安全保证强：** 其安全性基于已建立的安全原语（哈希函数），具有很高的可靠性。

* **缺点：**
    * **签名体积大：** 生成的签名往往比格基签名（如 Dilithium）大得多。
    * **有状态性 (Stateful) 或单次使用：** 某些设计（如 Lamport 签名）要求密钥只能使用一次，而更复杂的有状态签名（如 XMSS）需要持续跟踪已使用的密钥，这给实际部署带来了复杂性。

* **代表算法：**
    * **SPHINCS+ (无状态数字签名)：** 被 NIST 选为数字签名算法之一。它解决了传统哈希签名中“单次使用密钥”的限制，是目前最好的无状态哈希签名方案。

#### 3.3. 基于编码的密码学 (Code-based Cryptography)

这是历史最悠久的 PQC 家族，早在 1978 年就由 Robert McEliece 提出。

* **安全基础：**
    * **纠错编码理论：** 其安全性建立在**译码（Decoding）**一个带有随机错误的通用线性代码的问题之上，这被称为“**广义译码问题**”。
    * **困难性：** 找到一个随机线性编码的最优译码方法被认为是 NP-Hard（目前没有高效的经典或量子算法）。

* **优点：**
    * **安全性成熟：** 该算法（尤其是 McEliece 变体）经过了四十多年的研究，至今未被攻破，提供了极高的安全信心。

* **缺点：**
    * **公钥巨大：** 这是其主要的部署障碍。公钥可能达到几百 KB，是 RSA/ECC 密钥的数百倍，这会显著增加网络带宽和存储负担。

* **代表算法：**
    * **McEliece 密码系统**：最初的构造。


### 4. NIST 的选型：两大赢家（来自您的讲义）


在 2022 年，NIST 宣布了第一批标准化的核心抗量子加密算法，这些算法被称为 PQC 时代的两大赢家，它们分别针对公钥密码学的两个核心功能：**密钥交换/加密**和**数字签名**。

### A. 用于通用加密/密钥交换：CRYSTALS-Kyber

**用途：**

* **密钥交换 (Key Exchange)**：用于在不安全的通信信道上，安全地协商出一个共享的会话密钥（类似于您复习过的 **DHKE** 的作用）。
* **通用加密 (General Encryption)**：用于加密数据（类似于 **RSA** 公钥加密的作用）。

**算法详情：**

* **算法名称：** **CRYSTALS-Kyber**
* **数学基础：** **基于格的密码学 (Lattice-based Cryptography)**
* **为什么被选中？**
    1.  **密钥小巧 (Small Keys)：** 这一点对网络通信至关重要。Kyber 生成的公钥和密文体积很小，与现有的 ECC 算法相当，显著小于一些早期的 PQC 方案（如基于编码的密码学）。小密钥意味着网络开销低，可以方便快捷地在双方之间交换。
    2.  **操作快速 (Speed of Operation)：** 算法的加密和解密/封装和解封装过程非常高效，这对于处理大量连接的服务器（如 HTTPS 服务器）来说是决定性的优势。
    3.  **安全性高：** 基于难度经过长期验证的格理论难题，被认为能有效抵抗量子和经典攻击。

**总结：** Kyber 旨在成为下一代互联网安全协议（如 TLS 1.3）中**密钥协商**的首选。

### B. 用于数字签名：CRYSTALS-Dilithium

**用途：**

* **数字签名 (Digital Signature)**：用于验证信息或交易的真实性、完整性和来源（类似于您复习过的 **ECDSA** 和 **RSA 签名**的作用）。在数字交易、软件更新、身份验证等方面至关重要。

**算法详情：**

* **算法名称：** **CRYSTALS-Dilithium**
* **数学基础：** **基于格的密码学 (Lattice-based Cryptography)**
* **为什么被选中？**
    * 作为格密码学的代表，它在提供高安全性的同时，其**签名生成和验证速度**非常快，是高性能应用的理想选择。
