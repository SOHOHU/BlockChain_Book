# 数字签名

---

## 1. 密码学哈希函数（Cryptographic Hash Function）

**作用**

* 把任意长度消息 (M) 映射为固定长度的摘要 (h = H(M))（例如 256 位）。
* 在数字签名里先对消息做哈希，签名算法只对摘要 (h) 工作，显著提高效率并保证完整性。

**必要性质**

1. **原像不可逆（Preimage resistance）**：给定 (h)，难以找出任意 (M) 使 (H(M)=h)。
2. **第二原像抗性（Second-preimage resistance）**：给定 (M_1)，难以找到不同的 (M_2) 使 (H(M_1)=H(M_2))。
3. **碰撞抗性（Collision resistance）**：难以找到任意不等 (M_1, M_2) 使 (H(M_1)=H(M_2))。

**在签名中的两大作用**：

* **效率**：对大消息只签摘要。
* **完整性**：消息任何微小改动导致摘要完全不同（雪崩效应），签名验证会失败。

---

## 2. ECDSA（椭圆曲线数字签名算法）— 核心流程与意义

> ECDSA 将 ECC 的标量乘法与哈希结合，用于生成和验证签名。私钥是整数，公钥是曲线上对应的点。

### 2.1 关键参数与符号

* 曲线参数（公开）：曲线 (E)、基点 (G)、群的阶 (n)。
* 私钥（签名者 Alice）：整数 (d)（(1 \le d \le n-1)）。
* 公钥（公开）：点 (P = d\cdot G).

### 2.2 签名（Signer：Alice）

对消息 (M)，生成签名 ((r,s))：

1. 计算消息哈希：(h = H(M))（如 SHA-256，必要时做长度调整以适配 (n)）。
2. 选择一个**高强度随机数** (k)（会话随机数，必须对每次签名唯一且不可预测）。
3. 计算临时点： (R = k\cdot G)。设 (x_R) 为 (R) 的 (x)-坐标。
4. 计算 (r = x_R \bmod n)。如果 (r = 0)，重新选 (k)。
5. 计算 (s = k^{-1},(h + r\cdot d) \bmod n)。如果 (s = 0)，重新选 (k)。
6. 输出签名对 ((r, s))。

**安全注意**：如果同一 (k) 被重用或 (k) 泄露，私钥 (d) 会被立即推出（历史上多次因随机数不当导致私钥泄露）。因此 (k) 必须由可信 CSPRNG 生成或通过确定性方案（如 RFC 6979）派生。

### 2.3 验证（Verifier：Bob）

Bob 已知 Alice 的公钥 (P)，收到 (M) 与签名 ((r,s))：

1. 若 (r) 或 (s) 不在区间 ([1, n-1])，签名无效。
2. 计算哈希 (h' = H(M))。
3. 计算 (w = s^{-1} \bmod n)。
4. 计算标量：
   [
   u_1 = h' \cdot w \bmod n,\qquad u_2 = r \cdot w \bmod n.
   ]
5. 计算点：
   [
   V = u_1\cdot G + u_2\cdot P.
   ]
6. 如果 (V) 是无穷远点 (O)，签名无效。否则取 (x_V) 为 (V) 的 (x)-坐标；签名成立当且仅当
   [
   r \equiv x_V \bmod n.
   ]

**直观理由**（为何验证成立）：代数上可推导出 (V = (h + r d) k^{-1} G) 的 (x)-坐标与签名时的 (r) 相同（省略具体代数推导，这在算法标准里可详见证明）。
