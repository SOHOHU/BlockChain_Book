## IOP：Interactive Oracle Proofs

**IOP**是一种密码学证明系统，它扩展了传统的**交互式证明系统（Interactive Proofs）**，旨在解决效率和可扩展性的问题。

在传统的交互式证明中，证明者需要发送大量的中间计算结果给验证者，这会产生巨大的通信开销。而 IOP 引入了一个“预言机（Oracle）”的概念，它是一个只读的、可供验证者查询的数据结构。证明者将大部分复杂的数据打包成这个预言机，然后验证者可以根据自己的需要，**有选择地**向预言机进行少量查询。

简单来说，在区块链中，IOP就是验证者接收到来自PCS承诺后的一系列行为（包括挑战，接受，拒绝等）

### IOP 的工作原理

IOP 的核心思想是**用少量查询来代替大量的通信**。这个过程通常分为三个阶段：

1.  **承诺（Commitment）**：
    证明者将所有要证明的数据和计算过程压缩成一个简洁的“承诺”。就像我们在PCS所说的一样。证明者将这个承诺发送给验证者。

2.  **查询（Query）**：
    验证者基于证明者的承诺，随机选择一些特定的点进行查询。例如，验证者可能会问：“在多项式承诺的第50个点上的值是多少？”。即在随机的点展开多项式

3.  **响应（Response）**：
    证明者对验证者的查询做出回应，并提供相应的“证明”或“辅助数据”，来证明其响应的真实性。

正常来说验证者需要与证明者进行多次交互才会接受承诺，但是在区块链领域这是不现实的，我们希望尽可能节省gas。于是出现了**非交互式证明系统（Non-Interactive Proofs）**

### Fiat-Shamir 启发式：将 **交互式证明系统（Interactive Proofs）** 转换为 **非交互式证明系统（Non-Interactive Proofs）** 的方案

Fiat-Shamir 启发式是一种通用的密码学技术，它的核心思想是**用一个公开可验证的、无偏的函数来代替验证者的随机挑战**。

Fiat-Shamir 启发式将交互式证明系统的过程简化为：

1.  **证明者（Prover）**：
    * 证明者提交承诺和承诺的相关数据。
    * 证明者使用一个**加密哈希函数**（例如 SHA-256）对这些初始数据进行哈希运算。这个哈希值就作为**验证者的随机挑战**。
    * 证明者根据这个“虚拟”挑战来验证承诺。
    * 证明者将验证结果和数据打包成一个**单一的、非交互式的证明**。

2.  **验证者（Verifier）**：
    * 验证者收到证明和数据后，它会独立地对证明中的初始数据进行同样的哈希运算，**重新生成挑战**。
    * 验证者使用这个重新生成的挑战来验证承诺，来验证证明者的响应是否正确。

如果哈希函数是安全的，那么攻击者就无法提前预测挑战，也就无法伪造证明。这个过程将原本需要多轮通信的交互式协议，变成了只需一次通信的非交互式协议。

在zk-starks和zk-snarks中，Fiat-Shamir的具体流程是不一样的，我们在详细介绍zk-starks和zk-snarks流程的时候会详细的展开说明。

### 验证响应：

事实上验证者对证明者发起的验证有三种：

### 任务 1：零点测试 (zero-test)

$$\text{prove that } f \text{ is identically zero on } H$$
**证明多项式 $f$ 在集合 $H$ 上的**所有**点处都等于零**，即 $\forall a \in H, f(a) = 0$。

### 任务 2：求和校验 (sum-check)

$$\text{prove that } \sum_{a \in H} f(a) = b$$
**证明多项式 $f$ 在集合 $H$ 上的所有评估值之和等于一个已知值 $b$**。

### 任务 3：求积校验 (prod-check)

$$\text{prove that } \prod_{a \in H} f(a) = c$$
**证明多项式 $f$ 在集合 $H$ 上的所有评估值之积等于一个已知值 $c$**。

上述的 **评估集合 ($H$)：** 是由 $\omega$ 生成的一个大小为 $k$ 的乘法子群（或称**循环群**）。
    $$\text{Set } H := \{1, \omega, \omega^2, \dots, \omega^{k-1}\} \subseteq \mathbb{F}_p$$

零点测试是最简单也最常用的方法。使用零点测试的基于类似于因子定理的公式：

**$f$ 在 $H$ 上为零** 当且仅当 **$f(X)$ 可被 $X^k - 1$ 整除**。

我不加以证明，但是我们需要知道如何根据这个公式实现对证明者承诺的检验。

1.  **计算商多项式 $q(X)$：** $P$ 首先计算 $f(X)$ 除以 $X^k - 1$ 的商多项式 $q(X)$。
    $$q(X) \leftarrow f(X) / (X^k - 1)$$
    * **注意：** 如果 $f$ 真的在 $H$ 上为零，那么 $X^k - 1$ 就能整除 $f(X)$，此时没有余式。
2.  **准备发送：** $P$ 准备将计算得到的商多项式 $q(X)$ **承诺**给验证者 $V$。$q$ 也是一个多项式（且次数 $d'$ 约等于 $d-k$）。

3.  现在验证者要求证明者在点r同时打开f和q，**证明者 $P$** 收到 $r$ 后，在点 $r$ 处评估 $q(X)$ 和 $f(X)$ 的值，并将这两个值发送给 $V$。

4.  **校验等式：** $V$ 检查 $f(r)$ 是否满足由 $q(X)$ 导出的恒等式：
    $$\text{accept if } f(r) \stackrel{?}{=} q(r) \cdot (r^k - 1)$$
    * **含义：** 这个检查是验证在随机点 $r$ 处，**多项式恒等式** $f(X) = q(X) \cdot (X^k - 1)$ 是否成立。
    根据多项式零点理论，如果**多项式恒等式** $f(X) = q(X) \cdot (X^k - 1)$在r点展开成立，则对于所有的$f(X) = q(X) \cdot (X^k - 1)$都极大概率成立 → $f(X)能被 $(X^k - 1)$ 整除 → $f$ 在 $H$ 上为零 → 零点测试的条件成立 → f通过零点测试。

5.  **结论：** 如果检查通过，即 $f(r) = q(r) \cdot (r^k - 1)$，则 $V$ **接受**证明。
