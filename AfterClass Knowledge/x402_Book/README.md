### X402 学习笔记

这是我学习X402协议时做的笔记，主要记录一些核心概念和实际应用。说实话，刚开始接触的时候我也是一头雾水，所以尽量用简单的话来解释。

#### 什么是X402？
X402协议其实就是一种做微支付的方案。想象一下，你想为看一篇文章付1分钱，但是比特币的手续费就要几块钱，这显然不划算。X402就是为了解决这个问题而设计的。

#### 两种主要方式
目前主要有两种实现方式：一种是在区块链上直接处理，另一种是在链下处理。链下的方式更常用，因为速度快、费用低。

#### 实际应用
最出名的应用就是闪电网络了，它让比特币也能做微支付。还有一些其他的应用场景，比如内容付费、游戏内购买等等。
