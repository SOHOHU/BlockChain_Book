简单解释L1和L2先：
在以太坊中，L1 就是 以太坊主链（Ethereum Mainnet），L2 是 建立在 L1 之上的扩展网络
L2 通过各种技术（如 Rollup、Plasma、State Channel）把交易先在 L2 执行，然后再批量结算到 L1

本例在 L1 和 L2 的流程
1、用户在 L2 上发起交易 → 钱包构造交易，签名 → 发送到 L2 网络的 Sequencer 或验证者

2、L2 网络执行交易 → 修改账户余额状态（从发送方减去 ETH，加到接收方）→ 计算实际 Gas 消耗 → 只在 L2 内部记录交易状态

3、L2 整合多笔交易后向 L1 提交状态根（即可默克尔树根）或交易汇总，包括所有交易的最终状态

4、L1 节点验证汇总数据的正确性

综上，L2操作交易+L1记录交易，实现L1的安全性+L2高效性的组合

本例中：
L2 Fee 为常规计算，L1 Fee = L1 Gas Used × L1 Gas Price × L1 Fee Scalar（多了个gas系数）
但是L1 消耗由协议固定或由节点计算，且L1仅结算状态根或汇总，所以L1的手续费由L2 Rollup 提交者/协议支付（对EOA而言，Fee Scalar = 0）
