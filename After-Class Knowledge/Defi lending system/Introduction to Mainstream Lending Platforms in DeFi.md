

## 主流 DeFi 借贷协议简介
当前 DeFi 借贷市场中，有两大主流协议 **Aave** 和 **Compound** 。

### 共同点

| 特点 | 描述 |
| :--- | :--- |
| **借贷模式** | **资产池（Liquidity Pool）**模式。用户将资产存入池中获得利息，借款人从池中借款并支付利息。 |
| **抵押要求** | 绝大多数贷款都是**超额抵押（Overcollateralized）**。 |
| **利率模型** | 采用**浮动利率（Variable Rate）**和**稳定利率（Stable Rate）**。利率根据资产池的**利用率（Utilization Rate）**由算法实时计算，自动调整。 |
| **风险指标** | **健康因子（Health Factor, HF）**是衡量头寸安全性的核心指标，$\text{HF} \leq 1.0$ 时触发清算。 |

---

## 差异

虽然 Aave 和 Compound 的机制非常相似，但在具体参数设置和功能上略有不同。

| 参数 | 机制名称 | 描述 | Aave 示例 ($\text{ETH}$) | Compound 示例 ($\text{ETH}$) |
| :--- | :--- | :--- | :--- | :--- |
| **抵押比率上限** | **借贷比率 ($\text{LTV}$)** | 存入抵押品后，最高可以借出的金额比例。**$\text{LTV} < \text{LT}$** | $82.5\%$ | $75\%$ |
| **清算阈值** | **清算阈值 ($\text{LT}$)** | 当抵押品价值跌至该比例时，**触发清算** ($\text{HF}=1.0$）。$\text{LT} \geq \text{LTV}$ | $85\%$ | $80\%$ |
| **清算模式** | **清算类型** | 采用固定奖励的即时清算。 | 固定价差清算 | 固定价差清算 |
| **清算罚金** | **清算奖励 ($\text{Bonus}$/$\text{Spread}$)** | 协议给予清算人的折扣奖励，由**借款人承担**。 | $5\%$ | $8\%$ |
| **清算规模** | **平仓系数 ($\text{Close Factor}$)** | 单次清算中，清算人最多可以偿还的借款债务比例。 | $50\%$ | $50\%$ |
